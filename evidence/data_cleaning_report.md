# Data Cleaning Report

Row-by-row accounting of what the cleaning pipeline (`notebooks/01_data_cleaning.py`) removed from each raw dataset, and why. Generated by loading every raw and cleaned file and comparing row counts directly — not estimated.

## Raw versus Cleaned Row Counts

| Dataset | Raw rows | Cleaned rows | Rows removed | Reason |
| --- | ---: | ---: | ---: | --- |
| `track3_mandi_master.csv` | 60 | 57 | 3 | Duplicate `mandi_id` values, deduplicated (`keep="first"`) |
| `track3_mandi_arrivals.csv` | 25,750 | 25,000 | 750 | Exact duplicate rows, dropped |
| `track3_price_and_msp.json` | 12,000 | 12,000 | 0 | No row-level deduplication applied |
| `track3_transport_logistics.csv` | 10,400 | 10,000 | 400 | Exact duplicate rows, dropped |
| `track3_weather_sensors.xlsx` | 15,000 | 15,000 | 0 | No row-level deduplication applied |

No rows are dropped for missing or invalid *values* — those are retained and either converted, flagged, or set to `NaN`, as described below. Only exact duplicate rows (or duplicate `mandi_id` records in the master file) are removed entirely.

## Duplicate Detection Detail

- **Master**: 3 of 60 raw rows share a `mandi_id` with an earlier row. The first occurrence of each `mandi_id` is kept.
- **Arrivals**: 750 of 25,750 raw rows are exact duplicates (every column identical) of another row. `DataFrame.drop_duplicates()` removes all but the first occurrence.
- **Transport**: 400 of 10,400 raw rows are exact duplicates. Same handling as arrivals.
- **Price/MSP and weather**: the cleaning script performs no `drop_duplicates()` call on these two datasets, so their row counts are unchanged from raw to cleaned.

## Value-Level Cleaning (rows retained, values changed)

These do not change row counts — they convert or null individual fields within existing rows.

| Dataset | Operation | Rows affected |
| --- | --- | --- |
| Arrivals | Negative `arrival_quantity_qtl` set to `NaN`, flagged `invalid_negative_quantity` | See `quality_flag` counts in `mandi_arrivals_cleaned.csv` |
| Arrivals | Unit conversion: kg ÷ 100, tonnes × 10, into `arrival_quantity_qtl` | All rows with a recognised `unit` |
| Transport | Negative `transit_hours` set to `NaN`, flagged `invalid_negative_transit` | See `quality_flag` counts in `transport_cleaned.csv` |
| Transport | Transit times over 168 hours set to `NaN`, flagged `invalid_unrealistic_transit` | See `quality_flag` counts in `transport_cleaned.csv` |
| Transport | Distance converted to kilometres in `distance_km` | All rows with a recognised `distance_unit` |
| Weather | Temperature converted to Celsius in `temperature_c`; rainfall to millimetres in `rainfall_mm` | All rows with a recognised unit |
| Price/MSP | Currency symbols stripped and values coerced to numeric | All rows |

Field-level detail, including exact column names and `quality_flag` values, is documented in the [Data Dictionary](../DATA_DICTIONARY.md).
